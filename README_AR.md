# Battery Reminder - تطبيق تنبيه انخفاض البطارية

## ماذا يفعل التطبيق؟
يراقب مستوى بطارية جهاز أندرويد ويرسل إشعارًا متكررًا عندما تنخفض البطارية عن النسبة التي يحددها المستخدم.

## المزايا الحالية
- تفعيل أو إيقاف التنبيهات.
- تحديد نسبة البطارية، مثل 20%.
- تحديد التكرار بالدقائق، والحد الأدنى 15 دقيقة بسبب قيود أندرويد.
- إيقاف التنبيه أثناء الشحن.
- تشغيل فحص يدوي من زر Check Now.
- إعادة جدولة التنبيه بعد إعادة تشغيل الجهاز.

## طريقة التشغيل
1. افتح المشروع في Android Studio.
2. انتظر Gradle Sync.
3. شغّل التطبيق على جهاز أندرويد حقيقي أو محاكي.
4. اسمح بإذن الإشعارات إذا ظهر الطلب.
5. فعّل التنبيهات وحدد النسبة والتكرار ثم اضغط Save Settings.

## ملاحظة مهمة
أندرويد يقيّد المهام الخلفية. لذلك تم استخدام WorkManager لأنّه مناسب وآمن للتكرار في الخلفية، لكن أقل تكرار موثوق هو 15 دقيقة.

## المسار الفني المستخدم
- Kotlin
- Native Android Views
- WorkManager
- Notification Manager
- SharedPreferences
- BootReceiver
